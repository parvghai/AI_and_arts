# Example outputs

`aam_annotated_continuation.mid` is a small symbolic continuation generated by the annotation-aware experiment from an AAM MIDI track. It is included as an illustrative output, not as a musical-quality benchmark. The associated JSON sidecar records its seed composition, continuation boundary, generated notes, and timing diagnostics.

The example was generated from the AAM dataset (Ostermann & Vatolkin, 2022; [dataset DOI](https://doi.org/10.5281/zenodo.5794629)). The AAM record's license metadata is blank; users must check the dataset record and its terms before downloading, redistributing, or reusing its content. No raw AAM archives are included in this repository.
